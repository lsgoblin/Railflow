# 界面截图（UI mockup）

本目录存放 [ui-ux.md](../ui-ux.md) 引用的 9 张界面截图，取自原型（`src/frontend/`）的真实运行画面：01–03 为首页与一句话查票，04–09 为 Part I 已有页面。

## 运行原型

```powershell
java -m jdk.httpserver -p 8123 -d "$PWD\src\frontend"
```

打开 `http://127.0.0.1:8123/`。演示账户：

- 购票用户：`chen.yu@railflow.cn` / `railflow123`
- 管理员：`admin@railflow.cn` / `admin123`

访问 `http://127.0.0.1:8123/?reset=1` 可恢复初始数据；按住 Alt 点击「确认支付」或「确认退票」可查看失败状态。
