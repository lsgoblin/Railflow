# RailFlow 项目构想

本文保留 Part I 的历史构想。2026-11-16 起，新版产品方向与大致需求见 [design-spec.md](../design/design-spec.md)，旧设计与前端见 [归档](../../archive/20261116/README.md)。以下内容不代表新版范围。

RailFlow 是一个铁路车票预订与订单管理网页系统，参考铁路购票业务，使用测试车次、虚构乘车人和模拟支付完成购票演示。

用户可以查询直达车次、确认乘车人、下单锁座、模拟付款、查看订单，以及取消未支付订单或申请退票。管理员维护车次、票价和库存，查看业务记录。

## 核心流程

查询车次 → 确认行程与乘车人 → 下单锁座 → 模拟支付 → 查看订单。

未支付订单可以取消，也会在到期后自动失效；已支付订单可以按项目规则退票。

## 第一版范围

- 每单一名成人乘车人、一个席位，只提供一种席别。
- 只支持固定始发站至终到站的直达全程票。
- 使用测试数据，支付和退款均为模拟操作。
- 第一版不包含候补、换乘、改签、多人订单、优惠票和真实铁路或银行接入。

历史功能与业务规则见 [基本功能需求](../../archive/20261116/docs/design/requirements.md)。
