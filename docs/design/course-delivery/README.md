## 当前状态

- **已实现并通过逐项验收**：16 项 MVP——固定 GTFS 包整包导入（约 478 万行）、同车次直达查询、任意两站区间的真实铁路轨迹裁剪并叠加真实底图、同源 Spring Boot 托管前端。
- **仍未验证**：跨浏览器与真机移动端、并发压力、全量重导。
- **仍为设计（未实现）**：产品 AI 多轮、账号保存与恢复、历史票价、换乘衔接、外部 POI、地图点选组线。
